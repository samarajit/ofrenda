    How it works

    A small model, held to the cards

    Ofrenda runs llama.cpp on this machine and loads an open-weight Qwen3 1.7B model from a file in ./models. There is no API key, no account, and no outbound request, so the altar works with the internet off.

    The model is not allowed to invent. It must copy a phrase from one of the family's cards, say which card it took it from, and then write two sentences around it. Ofrenda checks that phrase against the card. If it does not match, the answer is refused, tried again, and finally replaced with the card itself, read word for word.

    Your record is data/altar.json. The photograph you put up stays in this browser. Delete the file and it is gone.

    Every GGUF model you like will work here. Swap the file, or point Ofrenda at a server you already run with OFRENDA_BACKEND.
